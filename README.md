🚴 Bikers Sales Analysis Dashboard | Microsoft Excel


📌 Project Overview

This project focuses on analyzing customer demographics and purchasing behavior to identify the key factors influencing bike purchases. Using Microsoft Excel, an interactive dashboard was developed to transform raw data into meaningful business insights.

The analysis helps businesses understand customer segments, income patterns, commuting behavior, and regional trends that impact sales performance.

🎯 Business Problem

Understanding customer purchasing behavior is crucial for improving sales strategies and targeting the right audience. This project aims to answer questions such as:

Which age group purchases bikes the most?
Does income influence purchasing decisions?
How does commute distance affect bike purchases?
Which customer demographics contribute most to sales?

📈 Key Insights
📌 Income Impact

Customers with higher average income show a greater tendency to purchase bikes.

📌 Age Group Trend

Middle-aged customers represent the highest proportion of bike buyers.

📌 Commute Distance Effect

Customers with shorter commute distances are more likely to purchase bikes.

📌 Demographic Influence

Occupation and education level significantly influence customer purchasing behavior.
